# Projects

This repository contains a few small static front-end projects built with plain HTML, CSS, and JavaScript.

- To do list: a local task tracker with add, toggle, delete, and localStorage persistence.
- Weather-app: a weather lookup app that calls the OpenWeather API.
- gym-website: a responsive gym landing page with navigation and sections.

All projects are plain HTML/CSS/JS and can be opened directly in a browser unless noted otherwise.
